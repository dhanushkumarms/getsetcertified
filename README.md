## 📌 Description  
**GetSetCertified** is a **Flask-based online certificate generator** that allows users to create and download customized certificates with ease.  
It supports both **bulk generation (via CSV upload)** and **single entry certificate creation**, making it ideal for events, workshops, hackathons, and academic use.

## ✨ Features  

✔️ **Bulk Certificate Generation** (Upload CSV with participant details)  
✔️ **Single Certificate Creation** (Customize with title, name, description, logo & signature)  
✔️ **Multiple Templates** to choose from  
✔️ **Automatic PDF Export** (High-quality certificates)  
✔️ **Custom Fonts & Colors** for personalization  
✔️ **Downloadable ZIP Archive** of generated certificates  


## ⚙️ Technology Used  

- **Backend:** Flask (Python)  
- **Image Processing:** Pillow (PIL)  
- **PDF Generation:** ReportLab  
- **Frontend:** HTML5, CSS3  
- **Templates:** Pre-designed certificate templates

# 🚀 Installation and Setup  

1. Clone the repository:  
   ```bash
   git clone https://github.com/your-username/getsetcertified.git
   cd getsetcertified
   ```

2. Create a virtual environment & activate:  
   ```bash
   python -m venv venv
   source venv/bin/activate  # For Linux/Mac
   venv\Scripts\activate     # For Windows
   ```

3. Install dependencies:  
   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:  
   ```bash
   python app.py
   ```

5. Open in browser:  
   ```cpp
   http://127.0.0.1:5000
   ```

## 🎯 Usage
- **Bulk Generation:** Upload a CSV file with participant details → Certificates are generated in bulk.
- **Single Generation:** Enter name, title, description, upload logo & signature → Instantly download certificate.
- **Download Option:** Get a ZIP file of all generated certificates.
