# **CountriQ - Country Quiz Platform**

Welcome to **CountriQ**, an interactive and engaging quiz platform designed to test your knowledge of world flags and countries.

### **Features**
- **Flag Frenzy!**  
  A thrilling quiz where players identify the correct country name based on the displayed flag, with a 30-second time limit.
  
- **Country Crunch!**  
  Challenge your memory in this chat-based game, where users provide country names based on the last letter of the country name in a fun, limitless format.
